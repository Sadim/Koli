## What the Extension is: and isn't

The Extension is a client-side tool: it adds right-click menu items
that send a link, selection, or page URL to an endpoint you configure
yourself. **The developer of the Extension does not operate a backend
service.** Every install talks only to a Google Apps Script Web App
that the person using it deploys and controls under their own Google
account, using the companion tool "Koli." The developer never receives,
stores, or has access to anything sent through the Extension: see the
[Privacy Policy](PRIVACY_POLICY.md) for full detail on data handling.

Because of that architecture, the developer has no visibility into, and
no control over, what any given install actually sends, to where, or
what the receiving Apps Script Web App does with it. You are solely
responsible for your own deployment, your own Web App's security (the
shared secret you set), and your own compliance with any terms that
apply to the sites you use the Extension on (including YouTube's own
Terms of Service: the Extension does not grant you any rights beyond
what those sites already allow).
