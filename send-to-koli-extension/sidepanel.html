Privacy

This extension talks only to the Web App URL you connect above — a script you deploy and control with your own Google account. Nothing is sent to Koli's developer or any third party, no usage analytics are collected, and your locks/columns/activity log stay in this browser (chrome.storage), never elsewhere. Source will be published under the MIT license so this can be checked, not just taken on faith.

Quick setup

1In Koli's Apps Script editor: Deploy → New deployment → Web app → Execute as "Me" → Who has access "Anyone."
2In Koli's Settings, save a shared secret, then click "Generate" next to Connection code.
3Tap a lock above, paste that one code in, then lock it.
